# Studio Working input expansion test

Use this to manually test that long tool inputs in Studio's Working view can be expanded.

Run this document in Studio. The model should call the bash tool exactly once with the command below.

After the tool call appears in **Working → Tools**:

1. Find the tool card's **Input** block.
2. It should show a truncation footer with **Show full**.
3. Click **Show full**.
4. Search visually or copy/load visible working and confirm the expanded input contains:
   - `WORKING_INPUT_EXPANSION_TEST_BEGIN`
   - `CROSSREF_DEEP_TAIL_MARKER`
   - `WORKING_INPUT_EXPANSION_TEST_END`

Please use the bash tool exactly once to run this command verbatim, including the long trailing shell comment. Do not shorten, paraphrase, or omit the trailing comment. Then stop.
